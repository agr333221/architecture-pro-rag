Золотой набор вопросов для автоматического тестирования RAG-бота (Задание 7).

Формат: каждый вопрос описан блоком из полей QUESTION / EXPECTED_STATUS / KEY_FACTS,
блоки разделены строкой "---". EXPECTED_STATUS принимает значения:
  answerable   - бот должен дать содержательный ответ по базе знаний;
  gap          - вопрос относится к сущностям, намеренно исключенным из индекса
                 (см. GAP_SOURCES в scripts/evaluate.py), бот должен корректно
                 сказать "не знаю" или дать неполный ответ без выдумывания фактов.
KEY_FACTS - ключевые слова/факты, которые скрипт evaluate.py ищет в ответе бота,
чтобы формально оценить полноту (используется только для answerable-вопросов).

Сущности для gap-вопросов (Вэлторн, Виндрал, Коррат Венн) выбраны по
результатам scripts/check_isolation.py - скрипта, который ищет упоминания
по основе слова (без учета падежных окончаний) по всей базе знаний, включая
docs/. Это исправление ошибки, найденной по результатам код-ревью:
предыдущая версия искала точную словоформу и пропускала склоненные формы
("Барона Илиана Кросса"), из-за чего два из трех прежних "изолированных"
объектов на самом деле упоминались в других документах. Из полного скана
18 крупных сущностей только Вэлторн оказался действительно изолирован
(0 посторонних упоминаний). Коррат Венн имеет 1 постороннее упоминание,
GAP_SOURCES исключает и его. У Виндрала посторонних упоминаний оказалось
больше (включая биографию главного героя Каэла Виндраннера, которую
исключить нельзя, и few-shot пример в rag_pipeline.py, впоследствии
замененный на не пересекающийся с gap-сущностями) - подробный разбор в
Project_template.md. GAP_SOURCES в evaluate.py исключает собственные
документы всех трех сущностей и документы-упоминания там, где это
возможно без вреда для answerable-вопросов (org_orden_hranitelei_potoka.md и
personage_ilian_kross.md соответственно).
